# Security policy

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could expose local
data or execute commands unexpectedly.

Use GitHub's private vulnerability reporting feature for this repository. If it
is unavailable, contact the repository owner through their GitHub profile and
request a private reporting channel.

Include:

- affected version;
- reproduction steps;
- expected impact;
- whether untrusted hook or socket input is involved;
- suggested mitigation, if known.

Do not include real API keys, tokens, prompts or source code.

## Supported versions

Until the first stable release, security fixes target the latest tagged release
and the `main` branch.
